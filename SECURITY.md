# Security policy

## Supported versions

Only the latest `main` revision is currently supported.

## Reporting a vulnerability

Do **not** report active vulnerabilities in public issues. Contact
`SECURITY_CONTACT_TODO` privately; the repository owner must replace this
placeholder before public deployment.

Include affected version/commit, reproduction steps, impact, and any suggested
mitigation. Maintainers will acknowledge a valid report, investigate privately,
prepare a fix, and coordinate disclosure. Scope includes Vault67 Community,
its Docker deployment files, and first-party dependencies/configuration.
